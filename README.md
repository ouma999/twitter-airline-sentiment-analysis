# twitter-airline-sentiment-analysis
This project perform a sentimental analysis focusing on major us airline data from twitter
# For my project i evaluated the three approaches one can use in NLP ; ML , Lexicon based and neural network
# I proceded to use the machine learning approach and split my data into 80/20 
#The data was tokenized by applying TF-IDF , stopwords removed and lematization done 
#Visualization was attained and the model was deployed to Streamlit to make it user friendly and interpretable to non technical audience.
